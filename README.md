# ECE_ESP32_PCB_Dionisio_IRREG

## Project Description

This project is a PCB design created for Electronics Engineering requirements. The repository contains the schematic diagram, PCB layout, Gerber files, source files, and screenshots related to the project design and development process.

The project was designed to demonstrate proper PCB layout techniques, circuit organization, and electronic design implementation using PCB design software.

---

# Features

- Custom PCB Layout
- Schematic Diagram Design
- 3D PCB Visualization
- Organized Gerber File Outputs
- Editable Source Files
- Compact and Functional PCB Design

---

# Components Used

- Resistors
- Capacitors
- ICs / Microcontrollers
- Connectors
- LEDs
- Voltage Regulators
- Header Pins
- Other Electronic Components

---

# Software Used

- EasyEDA / KiCad
- PCB Design Software
- Gerber Export Tools
